# Claude Code & AI Certification Track

This directory contains comprehensive study guides, concepts, and key learning deliverables for Anthropic's AI courses and official certification exams.

---

## Study Guides & Exam Prep

*   **[AI Fluency: Framework & Foundations](ai-fluency.md):** Focuses on the core human-AI collaboration mental model (The **4D Framework**), prompt architecture, XML tag structures, and evaluating AI output constraints.
*   **[Claude Code in Action & Exam Prep](claude-code-in-action.md):** Focuses on interactive terminal sessions with Claude Code, `CLAUDE.md` repository guidelines, planning vs. direct execution workflows, Model Context Protocol (MCP) integrations, and developer sandbox safety controls.

---

## Certification Objectives Covered

Both courses prepare candidates for the official **Claude Certified Architect – Foundations (CCA-F)** exam, which spans:
1.  **Agentic Architecture & Orchestration (27%)**
2.  **Claude Code Configuration & Workflows (20%)**
3.  **Prompt Engineering & Structured Output (20%)**
4.  **Tool Design & MCP Integration (18%)**
5.  **Context Management & Reliability (15%)**
